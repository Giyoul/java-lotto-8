# java-lotto-precourse
## 💪 프로젝트 소개
> 이 프로젝트는 우아한형제들 프리코스 과제로, 객체지향 원칙을 적용하여 로또 게임을 구현한 콘솔 애플리케이션입니다.
> 사용자가 로또를 구매하고, 당첨 번호를 입력하면 구매한 로또의 등수별 당첨 통계와 수익률을 계산하여 보여줍니다.

### 프로젝트 핵심 프로세스
- 객체지향 원칙
- TDD 개발 방식
- 책임 분리 및 단일 책임 원칙

---

## ✨ 주요 기능

### 1. 로또 구매
- 구매 금액을 입력받아 해당 금액만큼 로또를 자동으로 구매합니다.
- 1장당 1,000원 기준으로 계산합니다.
- 랜덤하게 생성된 6개의 번호를 가진 로또를 발행합니다.

### 2. 당첨 번호 입력
- 당첨 번호 6개를 쉼표로 구분하여 입력합니다.
- 보너스 번호 1개를 입력합니다.
- 당첨 번호와 보너스 번호의 유효성 검증을 진행합니다.

### 3. 통계 및 수익률 계산
- 구매한 로또들의 등수별 당첨 개수를 집계합니다.
- 총 당첨 금액을 계산합니다.
- 수익률 계산 및 출력을 진행합니다.

### 4. 등수 판정
| 일치 개수 | 보너스 볼 | 상금             | 등수 |
|-------|-------|----------------|----|
| 3개    | -     | 5,000원         | 5등 |
| 4개    | -     | 50,000원        | 4등 |
| 5개    | -     | 1,500,000원     | 3등 |
| 5개    | ✅     | 30,000,000원    | 2등 |
| 6개    | -     | 2,000,000,000원 | 1등 |

## 📁 프로젝트 구조
```markdown
src/main/java/lotto/
├── Application.java          # 프로그램 진입점
├── LottoController.java      # 컨트롤러: 전체 흐름 제어 및 예외 처리
├── LottoService.java         # 서비스: 비즈니스 로직 처리
├── InputView.java            # 입력 뷰: 사용자 입력 처리
├── OutputView.java           # 출력 뷰: 메시지 출력
├── Lotto.java                # 로또: 개별 로또 번호 관리
├── Lottos.java               # 로또 컬렉션: 구매한 로또들 관리
├── WinningLotto.java         # 당첨 로또: 당첨 번호 및 보너스 번호 관리
└── LottoStatistics.java      # 로또 통계: 등수별 정보 관리 (Enum)
```

  ↓

  ↓
Domain (Lotto, Lottos, WinningLotto, LottoStatistics)

## ▶️ 실행 방법
### 1. 사전 요구사항
- java 21

### 2. 실행 예시
```markdown
구입금액을 입력해 주세요.
5000

5개를 구매했습니다.
[40, 1, 42, 32, 37, 10]
[4, 44, 42, 1, 18, 13]
[39, 37, 10, 14, 43, 33]
[31, 34, 26, 44, 37, 16]
[28, 20, 26, 33, 9, 35]

당첨 번호를 입력해 주세요.
1,4,18,2,3,9

보너스 번호를 입력해 주세요.
20

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 100.0%입니다.
```

## ✈️ 게임 규칙
### 로또 번호 규칙
- 개수 : 정확히 6개 숫자
- 범위 : 1부터 45까지의 정수
- 중복 : 번호는 중복 허용되지 않음

### 당첨 조건
- 기본 번호 : 당첨 번호 6개 중 일치하는 개수로 등수 결정
- 보너스 번호 : 5개 일치 시 보너스 번호 일치 여부로 3등과 2등을 결정

### 수익률 계산
- 수익률 = (총 당첨 금액 / 구매 금액) x 100%

## ⚠️ 예외 처리
프로그램은 사용자의 잘못된 입력을 할 시에 예외를 발생시키고 에러 메시지를 출력한 후 재입력을 요청합니다.

### 구입 금액 예외
- 빈 입력
- 숫자가 아닌 입력
- 1,000원 미만
- 1,000원으로 나누어 떨어지지 않는 금액

### 당첨 번호 예외
- 빈 입력
- 쉼표로 구분되지 않은 형식
- 6개가 아닌 개수
- 1~45 범위를 벗어난 숫자
- 중복된 번호
- 숫자가 아닌 문자

### 보너스 번호 예외
- 빈 입력
- 숫자가 아닌 입력
- 1~45 범위를 벗어난 숫자
- 당첨 번호와 중복

### 에러 메시지 예시
```markdown
[ERROR] 구입 금액은 1000원 단위여야 합니다.
[ERROR] 당첨 번호는 빈 입력이면 안됩니다.
```
